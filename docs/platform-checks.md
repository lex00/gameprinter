# Platform checks, benchmarks and pins

Recipes that hold gp's runtimes to the same results on other platforms, and the scripts that time the build and list version pins. They came from game-printer's justfile and scripts/ (its check-cycle's wasmtime and x86_64 steps, scripts/test-vendor.sh, scripts/vendor/, scripts/upgrades/, scripts/build-timings.py and scripts/bench/), with what gameprinter has. Only `just check-vendor` is part of `just check`; the rest are run by hand, since each builds gp-wasm-check in release for another target.

| Recipe | What it checks | Time on an M-series Mac |
|---|---|---|
| `just check-wasm` | `gp-wasm-check` with no arguments plays `baselines/gp-testrom/buttons.toml` (compiled in) on the test ROM natively and under wasmtime (`wasm32-wasip2`), and both must give the committed digest; then Moss Hop's baselines under wasmtime, against the ROM `just mosshop` builds | 10 s warm |
| `just check-wasm-roms` | `gp-wasm-check replay-all STORE ROMS`: every recording in the store (`$GP_STORE`, else `$GP_HOME/store`) replayed natively and under wasmtime, as `gp replay --all` replays it. An NES recording finds its ROM by hash in `$GP_ROM_DIR`, an arcade recording its romset by identity among the zips there (crates/gp-wasm-check/src/arcade.rs), and a model recording needs none | 11 s natively, 17 s under wasmtime, for one Tapper and one Donkey Kong recording |
| `just check-x86_64` | An x86_64 build of `gp-wasm-check` under Rosetta: the test ROM's baseline and Moss Hop's. macOS only | 40 s cold |
| `just check-vendor` | `scripts/vendor/tetanes-core.sh --check`: the vendored emulator core is exactly its import plus `third_party/tetanes-core.patch`, offline; then `scripts/test-vendor.sh`, which edits a copy six ways and expects each to fail ([third_party/README.md](../third_party/README.md)) | 3 s |
| `just sprites-mosshop` | Moss Hop's sprites end to end: two baselines recorded into a store of its own, `gp sprites capture` (its proposal must equal `templates/mosshop/model.toml`), `gp sprites export` and `gp sprites import` | 7 s |
| `just bench` | gp-nes's criterion benchmarks (`crates/gp-nes/benches/hot_paths.rs`), each mean recorded as a metric `bench.criterion.<id>.ns` by `scripts/bench/criterion-metrics.py` | |
| `just build-timings` | A clean build and an incremental one after touching gp-nes, in `target/timings`, recorded as metrics, with cargo's per-crate report summarized by `scripts/build-timings.py` and copied to `$GP_HOME/reports/cargo-timing.html` | minutes |
| `just upgrades` | `scripts/upgrades/report.py`: every version pin (the toolchain and its targets, the workspace's crates, the editor's and site's npm packages, the MAME image, wasmtime, the inspector's browser, tetanes-core) with its newest release, the newest the pinned toolchain can use and what blocks the rest. Read only; `--offline` lists the pins alone, `--docker` also inspects the MAME base image's tag | |

`gp-wasm-check baseline ROM BASELINE...` checks baselines of a ROM built from source against that file, one `ok` or `FAILED` line each; `check-wasm` and `check-x86_64` run it on Moss Hop. Exit codes: 0 when every one passes, 1 on a mismatch, 2 when one can't be read or run. `replay-all` exits 0 when everything that ran matched (stale and skipped recordings don't fail), 1 on a divergence or when every recording was skipped, 2 on an error.

On 2026-11-13 every recipe above but `bench`, `build-timings` and `upgrades` (run `--offline` only) passed: the test ROM's digest `9ecd0e63...` natively, under wasmtime 48.0.7 and under Rosetta; Moss Hop's eight baselines under wasmtime and Rosetta; a Tapper recording of 10,933 frames and a Donkey Kong: Original Edition recording of 3,674 replayed identically natively and under wasmtime, as `gp replay --all` replays them.

Not brought: game-printer's Linux toolchain image (`docker/Dockerfile`) and its `docker-check` recipes, which ran the open tier in a container on both architectures. gameprinter's one image is MAME's (docs/oracle-mame.md). game-printer's `scripts/check/` (the gate's guards and test levels) is replaced by gameprinter's tool gate (docs/gate.md).
