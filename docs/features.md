# Features

Generated by `gp self features` from the registries in `crates/gp-model/src/feature_list.rs` (the model, the contract and the asset map) and `crates/gp-interp/src/mapping_features.rs`; `just docs` writes it. Don't edit it by hand.

A feature is an optional part of a format with a name. A model lists the ones it uses in `model.features`, a state mapping in `features`, or they're derived from the fields the file sets; a reader refuses a file that lists one it doesn't know, by name (docs/model.md, "Versions"). Adding one bumps no version. "Since" is the version it appeared in, from before versions stopped counting options, kept as a note; it's empty for a feature added after. A feature with no paths is found only by being listed.
