---
title: Bring in a game
description: Modelling a new game from a ROM you own isn't available yet.
---

**This path isn't available yet.** The tools for starting a new game from a ROM exist in the older version of Game Printer and haven't been brought over.

When it's built, you'll start from a ROM you own and end with a model of the game and a set of clips that prove the model matches it. You'd normally direct an agent to do the reading and modelling, and step in to judge what you see when you play.

What's missing:

- Registering a ROM and starting a new game's folder.
- The page where you play the original, record a clip and hand it to an agent.
- Support for a game on a cartridge type the emulator doesn't handle yet, which would first need a [change to the tool](../contribute/).

In the meantime, [improving a game](../improve/) uses the same model, clips and gate.
