# The public page's picture references (docs/web.md, "Picture
# references"): check-page.mjs plays each moment in the page's game frame
# to its frame (the section's run: Rivet Rodeo's clear-and-loop baseline,
# or a ROM version's route in ROUTES) and compares the SHA-256 of the
# game canvas's RGBA pixels with `sha256`. A difference fails the section
# naming the moment, with old, new and diff pictures in
# $GP_HOME/work/page-shots/. When a change is meant:
#   just web-page accept-pictures
# writes the new hashes here (and `state`, what the frame's state says).
# A moment with `pending` is played but not compared, and accept leaves it
# without a hash: remove the line once its reason is gone, then accept.
# `shows` is what a person sees there; the rest is written by accept.
